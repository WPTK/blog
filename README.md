# blog.wptk.org

Jekyll blog on GitHub Pages. Light mode only, Literata serif, WPTK Daylight colors. No theme dependency.

New post: add `_posts/YYYY-MM-DD-title.md` with front matter (`title`, `date`), then commit.

- Layouts: `_layouts/`
- All CSS: `_includes/style.css`, inlined into every page
- Font: Literata via Google Fonts, Georgia fallback
