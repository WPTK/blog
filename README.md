# blog.wptk.org

Jekyll blog on GitHub Pages, built on the WPTK design system (Midnight Modern, Manrope). No theme dependency.

New post: add `_posts/YYYY-MM-DD-title.md` with front matter (`title`, `date`), then commit.

- Layouts: `_layouts/`
- All CSS: `_includes/style.css`, inlined into every page
- Font: `fonts/Manrope-VariableFont_wght.ttf` (self-hosted)
