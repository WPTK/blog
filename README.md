# blog.wptk.org

Jekyll blog on GitHub Pages, built and deployed by GitHub Actions (`.github/workflows/pages.yml`) so custom plugins work. Tag pages at `/tags/<tag>/` are generated by `_plugins/tag_pages.rb`. Light mode only, Newsreader serif, WPTK Daylight colors. No theme dependency.

New post: add `_posts/YYYY-MM-DD-title.md` with front matter (`title`, `date`), then commit.

- Layouts: `_layouts/`
- All CSS: `_includes/style.css`, inlined into every page
- Font: Newsreader (self-hosted in `fonts/`, SIL OFL), Georgia fallback
